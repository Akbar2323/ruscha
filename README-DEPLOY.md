# RUSCHA — GitHub Pages

## O'zgarish (v2)
`vendor` papkasi `lib` deb qayta nomlandi. Sabab: GitHub Pages Jekyll
tizimini ishlatadi va `vendor` nomini xizmat papkasi deb hisoblab
chop etmasligi mumkin. Natijada React yuklanmay, sahifada {{ }} belgilari
xom holida chiqib qoladi.

## Yuklash
1. Repoda `Add file` -> `Upload files`
2. Bu papka ICHIDAGI hamma narsani sudrab tashlang
3. `Commit changes`
4. Repodagi ESKI `vendor` papkasini o'chiring (ichida index.html yo'q, xavfsiz)

## O'chirmang
- `CNAME` — domenni bog'lab turadi
- `.nojekyll` — bo'lsa yaxshi, lekin endi majburiy emas

## Yangilaganda
`sw.js` ichidagi `VERSION` raqamini oshiring (hozir `ruscha-v2`).
